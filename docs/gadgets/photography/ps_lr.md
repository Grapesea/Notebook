## 使用tips

### Photoshop

#### 添加版权文字并设置居中

```
©2026 Grapesea in xxx
```

步骤：

* 在图层面板中选中文字图层；

* 按 Ctrl + A，选中整个画布；
* 按 V 切换到“移动工具”；
* 在顶部工具栏点击：水平居中对齐；
* 按 Ctrl + D 取消选区
