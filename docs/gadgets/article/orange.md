# 我现在就想吃这个橘子

> 写于2026年10月30日凌晨

我盯着桌子上放着的金色的橘子，我饿了，我现在就想吃这个金色的橘子。

这袋橘子是我在十分钟以前买的。坦白讲，我本来不打算买它的。在四十分钟前，我结束了跟朋友的微信聊天，合上电脑去操场打卡散心。

然而天有不测风云。今晚的空气格外的冷，是一股不明不白的寒——杭州的寒是没有道理的，**浙大校园内的寒**更是没有道理的，你不知道为什么明明写了许多，练习了许多，却会突然被打击到。腹腔之内涌起微弱的愤怒，却抵御不了这股无名的寒冷。

我跑到一半就两眼昏花，不得不走完最后的路。手机里挂上微信，用信息麻醉着大脑。

Y的微信窗口弹了出来，问我要不要去吃烧烤。烧烤是弄口里的烧烤，不是北门垃圾站对面的烧烤，不是东北人在异乡开的烧烤，不是淄博烧烤在杭州的异化萌芽，这说明Y很有品味，我们都是浙江人，要吃本地化的产物。弄口里烧烤是什么？我怎么记得杭州一直有的店叫做弄堂里呢？哦可能是它的分店吧，**“老字号”杭州品牌年龄比我还小**，但是他就是老，我也不知道怎么回事。

此刻我的底层代码冲突了：我要减肥，我非常想要减肥——但是，我，饿了，我的小腹发酸。那应该怎么办呢？诶我发现只要能饱腹，喝水也可以！操场旁边的水果店没关门，称了5个**台州**橘子。奇怪的是，橘子是温岭的，并不是我惯常会买到的黄岩蜜桔——也许老板有他的道理吧。有的看起来老得快烂了，我挑挑拣拣选了5个最大最饱满的，才5块4。

我提着橘子挪上了宿舍的楼梯，用膝关节带动小腿，用大腿根带动膝盖，像丧尸一样挪到了寝室，把包丢在椅背上瘫下来。要不是我的脚充满了跟塑胶跑道的风充分接触后的气息，我就把袜子扔进脏衣篓，把脚丫子翘在显示器上面，整个人烂在椅垫里，幻想自己是一个被绑缚了手脚的待烤的乳猪，无忧无虑地享受人生中最无所事事的最后半小时 。

两个小时前我还在图书馆里看应用层的颠颠倒倒，C/S架构好复杂啊。你看这个C，它是维生素C的C，也是顾客的C，而且这个橘子的形状长得好像两个C拼在一起。我发现用左手抓起橘子就能得到一个C，可是右手在打字，没办法剥开它。啊这个C怎么这么坏啊，把我的脑子和手都勾住了。

我还是好饿，网络电波是不能吃的，C是一个不能吃的符号，玉泉和银泉的食堂也早就都关门了——顺便一提我今天中饭在银泉吃的新品，好难吃——我也不是《重启咲良田》里面的神秘人，靠着信息进食填饱肚子。互联网论坛已经是垃圾场了，在屎里淘金会噎死自己。我深呼吸了一口，双手合十，试图用意念把橘子映射到现实世界再剥开来吃。

我的眼睛终于对焦上了这个黄色的橘子。我用大臂操控小臂，腕部操控左手，用力扣进了橘子的下部——水分太过饱满溅了我一整张桌子——我的白色桌布染成全黄了！我不由得吓了一大跳。

室友的水杯pia叽掉在了地上，发出咣当的巨响。这一瞬间我的一半人生亮起了黄灯，半段走马灯亮了起来，仿佛想让我忏悔为什么要对一个橘子发电。我不由得想起刘伯温写的文章：“**出之烨然，玉质而金色。**”哦这橘子，这本来是完美的橘子，**本该跟达芬奇的鸡蛋一样充满了严谨科班气息，本该跟塞尚的苹果一样充满了想象力的外壳，本该跟孔融的梨一样充满了美德的浸润**，但是我眼前的橘子七零八落，充满了人类撕裂后的孤寂的美。但是那破碎的废墟之上，还有**最后一个惊喜**等待着我——

一条白色的蛆探出头，向我微微致意，并且继续探出身子好让我瞻仰它优美的流线型身躯。

我的腿脚一下子好了，我把橘子扔进垃圾桶打好包飞奔到楼下一气呵成。

现在我饿了，但我不想吃橘子了。
