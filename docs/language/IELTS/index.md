## 经验

???+ info "[Kasa_ZYY: 雅思自学流程介绍，以及一些奇技淫巧-bilibili](https://www.bilibili.com/video/BV1cyDKBLEXY)"

    剑桥雅思是最好的备考资料.
    
    日常学习流程：
    
    * 9:00-12:00 背/复习/过单词
    * 13:00-15:00 做真题
    * 15:00-17:30 复盘 精听
    * 19:00-22:00 写作文 改作文
    * 不背单词：每日100-150 **绝对不能含糊，不懂就是不懂，3s之内想不起来就是不懂，总之要练到能迅速回答**
    * **一日之计在于晨，早起不要碰手机，可以喝咖啡，仪式感**
    
    听力：
    
    * 听力精听，不看翻译不改错，语法 词汇 定位重点关注.
    * 填空题要明确自己错在什么地方，拼写/单复数/大小写 重点关注.
    * 数字(phone/passport etc.)/月份/星期/颜色/国家必须迅速反应
    * M&N 字母发音有可能分不清，第一遍听清楚人名/地名（eg. 雅思哥模考C10-Test3的"Wombat"）
    
    阅读复盘：
    
    * 搞清题目意思
    * 多问AI
    * 真正搞懂一篇文章：把长难句语法结构搞清楚，让出现生词不影响自己做题
    
    写作：
    
    * 写作尽早练习
    * 多写字
    * 减少语法问题
    * 多用AI，让AI基于自己的水平来提升
    
    口语：
    
    * 花时间研究题库，磨格式
    
    技巧：
    
    * 耳机音量不要太大，降噪耳机保持70左右
    * 放听力前注意观察环境
    * 可以带水，含一口缓解紧张
    * 删掉各种影响心态的软件
    * 建议先做18-20，同时不忽视老题
    * 远离手机

???+ info "[医疗废物：雅思首考8.0屠鸭攻略分享 - CC98论坛](https://www.cc98.org/topic/6455542)"

    （熟悉各模块的题型、做题技巧等）既可以靠报班，也可以靠自学。对于像我这种自控力并不好的uu，可以考虑报班来点外力辅助，但实话说性价比并不高。自学完全可以，98资源帖，加上一些b站视频，基本够用了（详情可以在版内以雅思为关键词找一些自学经验帖~）
    
    首先是熟悉各模块题型。例如听力前两篇生活化话题、后两篇学术化话题，第1、3篇是对话、第2、4篇是独白，口语part2会有1min准备时间等。
    
    接着是学一些做题技巧，然后再去大量做题，因为做题是运用这些技巧并且锻炼熟练度的过程！
    
    阅读方面，一个很重要的技巧是，哪些题型是顺序出题，哪些题型是乱序出题，事关在文中找定位和要不要选NOT MENTIONED。此外，建议学一学如何找定位词、平行阅读法等等，可以很明显地提高做题速度。
    
    听力方面，个人认为地图题的读题顺序有必要专门学一下。如果是一个公园、博物馆等场所，从入口处开始看（一般在图的正下方）；如果是交通类的，沿着主干道来读，再把那些选项字母的位置的走一遍.
