## 经验

> 来自[Kasa_ZYY: 雅思自学流程介绍，以及一些奇技淫巧-bilibili](https://www.bilibili.com/video/BV1cyDKBLEXY)：
>
> 剑桥雅思是最好的备考资料.
>
> 日常学习流程：
>
> * 9:00-12:00 背/复习/过单词
> * 13:00-15:00 做真题
> * 15:00-17:30 复盘 精听
> * 19:00-22:00 写作文 改作文
> * 不背单词：每日100-150 **绝对不能含糊，不懂就是不懂，3s之内想不起来就是不懂，总之要练到能迅速回答**
> * **一日之计在于晨，早起不要碰手机，可以喝咖啡，仪式感**
>
> 听力：
>
> * 听力精听，不看翻译不改错，语法 词汇 定位重点关注.
> * 填空题要明确自己错在什么地方，拼写/单复数/大小写 重点关注.
> * 数字(phone/passport etc.)/月份/星期/颜色/国家必须迅速反应
> * M&N 字母发音有可能分不清，第一遍听清楚人名/地名（eg. 雅思哥模考C10-Test3的"Wombat"）
>
> 阅读复盘：
>
> * 搞清题目意思
> * 多问AI
> * 真正搞懂一篇文章：把长难句语法结构搞清楚，让出现生词不影响自己做题
>
> 写作：
>
> * 写作尽早练习
> * 多写字
> * 减少语法问题
> * 多用AI，让AI基于自己的水平来提升
>
> 口语：
>
> * 花时间研究题库，磨格式
>
> 技巧：
>
> * 耳机音量不要太大，降噪耳机保持70左右
> * 放听力前注意观察环境
> * 可以带水，含一口缓解紧张
> * 删掉各种影响心态的软件
> * 建议先做18-20，同时不忽视老题
> * 远离手机

## 考点选择

> [番茄杀西瓜：速通口写的雅思7.5经验贴 - CC98论坛](https://www.cc98.org/topic/6493947):
>
> 我选的是考试院的考点，离玉泉近，很方便，周边有商场。考场设施挺好的，工作人员态度特别好，说话温柔，缺点是键盘真的很难打，很硬。
>
> [道理尿尿：首考雅思7.0经验帖 - CC98论坛](https://www.cc98.org/topic/6465985):
>
> 如果住在别的校区，在华家池考上午场的话，建议前一晚住在附近的酒店，这样比较保险，lz住的是98经验贴推荐的青皮树。酒店骑共享单车到考场差不多6min,我下午考口语，所以免费延迟到1点退房了。建议提前40-60min到达考场，另外身上除身份证外的所有物品都需要放在储物柜，包括耳钉，护身符等等。
