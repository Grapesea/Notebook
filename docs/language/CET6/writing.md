    * 语法是否有误

    * 是否有自己鲜明的、独到的观点

    * 作文结构是否合理（三段式）、是否超过字数、是否按照要求（要抄写首句）

    * 加分项： 使用高级词汇、高级从句；字迹工整；引用名人事例（存疑）

    以 "how to balance work and leisure"作文题为例：

    第一步：审题（How / Why）

    第二步：框架结构

    * 第一段：引入现象+观点（正反结合）+过渡句

        eg. As far as I'm concerned, ... / ... underscores ...

    * 第二段：2-3个观点
