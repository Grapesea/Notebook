### Data Spaces

> 行业标准：ISO/IEC DIS 20151

* 定义：Governance framework and supporting services.

* 目标：build trustworthiness and enabling data sharing through an agreed set of policies, semantic models protocols and processes.
* 重要特点：
    * distributed systems
    * ruled by a governance framework/rulebook
    * secure and trustworthy data transactions
    * data sovereignty
    * enables value through use cases
