## 软件开发idea

### Mailbox-Auto-Deliverer

基于Windows系统开发的软件，具有完善的前后端，前端是悬浮在桌面的多邮箱新邮件通知，允许实时查看多个邮箱账号的新邮件（可过滤广告邮件，设定 ）；后端在本地文件夹存储账户数据（也就是不上传到网络中），允许通过验证码登录邮箱添加自己的账号信息

### Photo-Graphics

CC BY-NC-SA 4.0协议

“您的私人作品管理助手”

现在我希望制作一个安卓手机端/Windows端的应用，无需登录，用户可以导入自己的.raw/.jpg/.png等格式图片成为便于可视化分类、整理和查找的图谱，多模态AI模型做初步处理后根据一些预设维度对照片进行初步分类，同时支持用户做针对每张图片的自定义标签化设置。

功能：

* 支持每次加入照片后，AI分析给出推荐tag，用户可以选择直接采用或者自己添加tag，图片会被当作新节点添加到图谱内；
* AI模型配置：调用具备多模态能力的模型的API（目前比较看好的是Deepseek V4-Flash, ChatGPT 5.6 luna medium），需要用户自行在个人中心配置 base url 和 api key（本地存储在`.config/`下）；
* 主页面是最顶层图谱展示，由多个category构成；分为多个可以滑动或点击某个按钮实现切换的图谱，包含了基于相片分类的图谱、基于图片tag的图谱等等
* 在图谱界面点击每个category或者tag的节点之后，图谱局部放大，可以显示图片节点的缩略预览图；再点击图片节点会进入图片详细信息界面，支持自定义备注和元信息查看；
* 图片上传后将软链接存储到软件文件夹内的缓存中（`.photo-graphics/`），需要解决不同路径图片的存储问题以及图片不在原先路径后的解决方案（可能需要参考Adobe Photoshop）
